# 2026-08-26 — Faz 6: Google ile giriş

## Ne yapmayı planladın?

- Faz 6'ya geçmek: yalnızca Google OIDC. Microsoft / GitHub / LinkedIn'e girmemek (onlar Faz 7).
- `Microsoft.AspNetCore.Authentication.Google` paketini eklemek ve handler'ı DI'da kaydetmek.
- Harici login akışını servise yazmak: Google'dan gelen kimliği yerel `AspNetUsers` kaydına bağlamak, yeni kullanıcıya `User` rolü vermek.
- `AccountController`'daki sahte `ExternalLogin` action'ını gerçek `Challenge` + `ExternalLoginCallback` ile değiştirmek.
- Login sayfasındaki sabit dört butonu kaldırıp gerçekten kayıtlı olan sağlayıcıları listelemek.

## Hangi sorunlar ile karşılaştın?

- Login sayfasında Microsoft / GitHub / LinkedIn butonları sabit duruyordu; kayıtlı olmayan bir scheme'e challenge atmak çalışma zamanı hatası verir.
- Identity'nin `GetExternalLoginInfoAsync` metodu, challenge sırasında `AuthenticationProperties.Items` içine konan `LoginProvider` anahtarını arıyor. Bu anahtarın adı Identity içinde private const; Web katmanına elle string yazmak istemedim.
- `dotnet run --launch-profile https` "address already in use" ile patladı; 5059 portunu önceki oturumdan kalan bir instance tutuyordu.
- Bir denemede `dotnet run` komutuna fazladan argüman geçince launch profile devre dışı kaldı, `ASPNETCORE_ENVIRONMENT=Development` set edilmedi ve User Secrets okunmadı — uygulama "connection string bulunamadı" dedi.

## Bu sorunları nasıl çözdün?

- `IAuthService.GetExternalProvidersAsync` eklendi; view artık `Model.ExternalProviders` üzerinden dönüyor. Sağlayıcı yoksa "or" bölümü hiç render edilmiyor. Faz 7'de bu liste `IdentityProviders` tablosundan beslenecek.
- Challenge verisi için `ExternalLoginChallenge` DTO'su yazıldı. Items sözlüğünü Infrastructure'da `SignInManager.ConfigureExternalAuthenticationProperties` dolduruyor; Web katmanı yalnızca taşıyor. Böylece magic string Infrastructure'da kaldı ve Application katmanı ASP.NET'e bağımlı olmadı.
- Google handler'ı yalnızca ClientId ve ClientSecret varsa kaydediliyor. Secret'ı olmayan bir makinede uygulama yine açılıyor, sadece Google butonu görünmüyor.
- Eski instance `pkill` ile kapatıldı, sonra uygulama temiz açıldı.
- `dotnet run --project src/TablerAuth.Web --launch-profile https` şeklinde, fazladan argüman olmadan çalıştırıldı.
- Doğrulama: geçici sahte ClientId/Secret ile `POST /Account/ExternalLogin` 302 döndü ve `accounts.google.com`'a `redirect_uri=https://localhost:7258/signin-google` ve PKCE (`code_challenge_method=S256`) ile gitti. Sahte değerler sonra User Secrets'tan silindi; gerçek değerleri Google Cloud Console'dan alıp eklemek kaldı.
